# Disclosure Boundary

## Included publicly

- anonymized problem statement;
- architecture and engineering decisions;
- QA methodology and pass/fail summary;
- technology stack;
- limitations and engineering lessons.

## Intentionally excluded

- Pine Script implementation source;
- client name / username / profile;
- private screenshots or screen recordings;
- private conversations;
- contract and payment information;
- private repository links;
- credentials or account details;
- proprietary reference material;
- delivery ZIPs and binaries.

## Relationship to the private repository

The private OSYSTIC repository is the engineering source of truth.

This public repository is an independently sanitized documentation artifact. It is not a mirror, fork, or reproducible source release.
