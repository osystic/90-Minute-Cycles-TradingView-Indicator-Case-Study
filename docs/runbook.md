# Public Case-Study Runbook

## Purpose

Keep this repository portfolio-safe while preserving enough technical depth to demonstrate engineering capability.

## Before publishing a change

Confirm that the change contains none of the following:

- confidential Pine Script source;
- client identity or usernames;
- private screenshots, messages, recordings or links;
- credentials, account IDs or payment data;
- proprietary reference assets;
- private repository URLs.

## Allowed additions

- sanitized architecture;
- technical methodology;
- anonymized QA summaries;
- engineering lessons;
- non-confidential diagrams;
- public-safe limitations.

## If sensitive material is discovered

1. Remove the sensitive content from the public branch.
2. Determine whether a credential or account identifier requires rotation.
3. Check nearby history for related exposure.
4. Update the disclosure boundary if the incident reveals a process gap.
5. Preserve confidential source only in the private engineering repository.
